예시 화면 사용법

  1. 왼쪽에서 상황과 조건을 고릅니다.
  2. 이전·다음 또는 Slider로 흐름을 따라갑니다.

  5. 줌인 상태에서 다음·이전·재생을 누르면 먼저 전체 보기로 돌아간 뒤 단계가 이동합니다.
